## 摘要

我们在[报告五](05_hardware_alignment.zh.md)的硬件对齐设置下（光流 + ToF + 路线 B，v4 基座）重做了报告四的对照臂，并加入
分布外（OOD）测试。跑完**约 18,000 个快仿真回合和约 1,900 次 Gazebo 飞行**后，结果有正有反，这里如实报告：

- **C0：网络是必需的。** 关掉大脑，或去掉它的 looming 输入，每 100 m 接触在 lowbox 上增加约 10 倍，在 cage20 上增加约
  40 倍（均 p < 10⁻⁵）。
- **C2：真实接线优于保持度分布的打乱接线**，方向一致但强度弱：两个场景里每 100 m 接触都低于全部 5 个 shuffle，两级
  bootstrap 置信区间刚好包含 0。
- **C4：但读出层不是瓶颈。** 在完全相同的优化预算下，bypass 臂（去掉 LIF 网络，用 8 个可调增益把视觉特征直接映射成
  伪 DN 发放率）优于 intact 网络：8 对 8 个种子，Gazebo lowbox 有接触的运行中位数 2.5 对 10.5（精确 Mann-Whitney
  p = 0.015），在没有选择偏差的独立快仿真测试上也成立（p = 0.010）。快仿真的排序能迁移到 Gazebo（ρ = 0.75）。代价是
  bypass 在空场里自发转向更多（3.3 对 1.8 次/分，p = 0.04）。
- **D：第一个支持连接组的结果。** 去掉箱子和地面的纹理（notex）后，bypass 失去优势而 intact 没有退化：快仿真里有接触
  的运行变化量 +6.5 对 −2.0（p = 0.001），Gazebo 50 个世界上复现（+4.0 对 −1.5，p = 0.001）。在风扰、半边相机遮挡、低光照、
  ToF 故障下，bypass 仍然领先或两者退化相当。

## 1. 对照臂

| 臂 | 内容 | 是否优化 |
|---|---|---|
| v4 / v4_eff | 手调 MiniFly v4（+ blank 传出副本） | 否 |
| brainoff | LIF 网络静默，解码器看不到 DN 活动 | 否 |
| noloom | 去掉网络的 looming 输入 | 否 |
| shuffle1–5 | Maslov–Sneppen 边交换，严格保持入度、出度和权重符号 | 否（C2 检验的是接线本身） |
| **intact `h2_s1..8`** | v4 基座，在 `v4hw` 解码器空间（22 维）上做 CMA | 8 个 CMA 种子 |
| **bypass `c4_s1..8`** | 去掉网络；`v4hw` + 8 个从视觉特征到伪 DN 发放率的增益（30 维） | 8 个 CMA 种子 |

intact 和 bypass 的协议完全相同：适应度 v3、随机化光流快仿真、训练世界一半为 lowbox、20 代 × 12 候选 × 12 回合、
CMA 种子 1–8，按留出集最优代导出。

## 2. C0 / C2：去掉或重接网络

![C0 C2](figures/fig11_c0_c2_hw.png)

*图 1. 服务器 Gazebo，574 次运行，与 v4 配对（左、中）；同样对照臂的快仿真预筛（右，2,782 个回合）。*

| 臂 | lowbox 每 100 m 接触 | lowbox 有接触的运行 | cage20 每 100 m 接触 | cage20 有接触的运行 |
|---|---|---|---|---|
| v4（真实接线） | 1.8 [0.7, 3.1] | 10/50 | 1.1 [0.3, 2.2] | 6/32 |
| shuffle 1–5 | 3.6 – 5.9 | 11–15/50 | 1.4 – 4.4 | 6–9/32 |
| 去掉 looming | 21.4 | 33/49 | 47.2 | 32/32 |
| 关掉大脑 | 18.2 | 33/50 | 45.2 | 32/32 |

- **C0 强烈成立**，Gazebo 和快仿真都是如此。
- **C2 方向成立，强度偏弱。** 两个场景里真实接线的每 100 m 接触都优于 5/5 个 shuffle；“shuffle − 真实”的两级 bootstrap
  （先抽实例，再抽种子）在 lowbox 为 [−0.07, +7.5]，cage20 为 [−0.8, +5.7]。打乱后的网络躲避更少：lowbox 上 4/5 个
  shuffle 最小间隙更小、覆盖率更高。快仿真里效应清楚得多（cage20 上 5 个 shuffle 全部为 17–23/32，v4 为 6/32）。

## 3. C4：bypass 对 intact，逐种子比较

![bypass 对 intact](figures/fig12_bypass_vs_intact.png)

*图 2. 每个点是一个 CMA 种子。左：留出集最优适应度（在留出集上挑选，有向上偏差）。中：选择集之外 150 个 lowbox 回合的
独立快仿真测试。右：Gazebo，ROG，lowbox_s0–49，与 v4 配对。*

| 种子 | bypass：快仿真 / Gazebo lowbox 有接触的运行 | intact：快仿真 / Gazebo lowbox 有接触的运行 |
|---|---|---|
| 1 | 12/150 · **3/49**（p = 0.02） | 33/150 · 6/50 |
| 2 | 13/150 · **2/50**（p = 0.004） | 32/150 · 15/49 |
| 3 | 52/150 · 13/50 | 38/150 · 10/50 |
| 4 | 17/150 · 6/50 | 32/150 · 11/50 |
| 5 | 22/150 · **2/50**（p = 0.004） | 35/150 · 6/50 |
| 6 | 10/150 · **2/50**（p = 0.004） | 27/150 · 15/50 |
| 7 | 20/150 · 5/50 | 28/150 · **3/50**（p = 0.04） |
| 8 | 14/150 · **2/50**（p = 0.004） | 47/150 · 16/50 |
| v4 | 34/150 · 11/50 | |

- 8 个 bypass 种子的留出集适应度全部好于 8 个 intact 种子（−0.61 … −0.96 对 −1.24 … −1.96，p = 0.00016），但这是
  选择集。在独立快仿真测试上，7/8 个 bypass 种子比 v4 少撞，intact 没有一个种子做到。种子层面中位数 15.5 对 32.5
  （p = 0.010）；每 100 m 接触 1.65 对 5.34（p = 0.007）；cage20 6.5 对 12.5（p = 0.005）。
- Gazebo 中 bypass 有接触的运行合计 35 次，intact 82 次（中位数 2.5 对 10.5，p = 0.015）。c4_s3 在两个仿真器里都是
  反例。c4_s1 换一组大脑种子（k + 100）复跑，方向一致（5 → 1）；两轮合计 98 对，救回 14、新增 2，McNemar p ≈ 0.004。

![迁移](figures/fig13_twin_gazebo_transfer.png)

*图 3. 左：逐配置比较快仿真和 Gazebo 的有接触运行数（Spearman ρ = 0.75，p = 0.0009）。右：bypass 的代价——空场里
误转向更多（c4_s6 达 6.4 次/分）。*

![收敛曲线](figures/fig15_c4_h2_curves.png)

*图 4. 优化过程中的留出集适应度。bypass 起点更好且始终更好，大部分收益在第 4 代就已出现。很多 bypass 增益停在边界上
（c0 = 60、k_flow = 3、th_gf = 0）。*

**解读。** 在同样的预算下，把光流直接接到转向，比只调网络的读出层效果更好。这一结论对“连接组有用”不利，这里如实报告。
与 C0/C2 合起来，一致的解释是：网络结构有贡献（去掉或打乱都会变差），但在这个任务里，读取网络的解码器不是性能的瓶颈——
一个调好增益的直接视觉—运动映射至少一样好，代价是更多的自发转向。

## 4. D：分布外测试

`rl/twin.py` 新增 `TwinDrone(ood=...)`，使用独立的随机数流（分布内路径保持逐位一致）：

| 模式 | 改动 | 强度（在 v4、lowbox_s0–19 上选定，分布内为 2/20 次有接触） |
|---|---|---|
| lowlight | 相机增益 ×0.3、噪声 0.02 | 6/20 |
| notex | 箱子单一平色、无明暗、无胶带、地垫纯色、无地面贴条 | 3/20 |
| halfcam | 遮住画面的左半或右半 | 8/20 |
| wind | 稳态漂移 0.03 m/s + 阵风 0.10 | 12/20（漂移 0.12/0.06/0.03/0 → 20/19/12/5） |
| tof | 每秒 10% 概率出现 1–4 s 读数卡死，另有 3% 超量程；光流尺度使用错误读数 | 3/20 |
| ghost | 箱子不可见但仍会撞上 | 11/20 |

`rl/ood.py` 在与独立测试相同的世界、大脑种子和随机化下运行 16 个导出配置加 v4，所以分布内结果可直接作配对基线
（11,736 个快仿真回合，0 个错误，Mac mini + Jetson）。`gazebo/ood_world.py` 生成 Gazebo 世界的 notex 和 ghost 版本
（notex：自发光单色箱子，无胶带、无阳光明暗，地垫为均匀灰 0.425；ghost：只保留碰撞体）；ROG 上共 994 次（notex
lowbox_s0–49 × 17 个配置，ghost / 正常 cage20 × 8 × 9 个配置）。

![OOD](figures/fig14_ood.png)

*图 5. 每个种子有接触的运行数相对分布内的变化。这是 FLYNN 一类论证所要求的检验：如果连接组有用，intact 应该退化更少。*

| 模式 | lowbox Δ bypass / intact（p） | cage20 Δ bypass / intact（p） | 解读 |
|---|---|---|---|
| **notex** | **+6.5 / −2.0（0.001）** | +1.0 / −3.5（0.05） | bypass 失去优势（11.5 对 8.5，p = 0.57）；intact 更稳 |
| lowlight | +4.5 / 0.0（0.23） | +1.5 / +1.0（0.72） | 优势缩小，不显著 |
| halfcam | +9.0 / +10.5（0.38） | +24.5 / +19.0（0.04） | cage20 接近 31/32，饱和 |
| wind | +17.5 / +21.5（0.015） | +5.5 / +9.0（0.13） | bypass 退化更少 |
| tof | 0.0 / −1.5（0.72） | +0.5 / +2.5（0.20） | 两组都基本不受影响 |
| ghost | +24 / +19（0.20） | +10.5 / +18.5（0.05） | 避障来自视觉；bypass 在 cage20 的一部分优势是“盲”的 |

- **notex 在 Gazebo 中复现**（ROG，lowbox_s0–49 × 17 个配置，10-13 从 20 个世界扩充到 50 个）：分布内 bypass 少撞
  （中位数 2.5 对 10.5，p = 0.015）；去纹理后差距消失（6.5 对 8.0，p = 0.65）；种子层面变化量 +4.0 对 −1.5（p = 0.001；
  前 20 个世界时为 +1.0 对 −1.5，p = 0.028）。注意：intact 去纹理后反而略少撞，可能是因为自发光的单色箱子与地面对比更强，
  不能直接理解为 intact 变好。去纹理世界起飞失败偏多（解锁时报“没有位置估计”，集中在 s25–s38），46 次全部补跑成功。
- **Gazebo ghost**（cage20 × 8，v4 + 种子 1–4）：所有配置都大量接触（intact 4 个种子全部 8/8，v4 8/8；bypass 4、8、3、8；
  p = 0.34）。快仿真里“bypass 看不见也少撞”只出现在 c4_s1/s3 上，在 Gazebo 里很弱。

## 5. 对论文意味着什么

- 成立的主张：网络是必需的（C0）；真实接线在方向上优于打乱接线（C2）；快仿真的排序能迁移到 Gazebo（ρ = 0.75），用快
  仿真做筛选是合理的。
- 不成立的主张：“优化连接组的读出层优于直接的视觉—运动映射”。并不成立（C4），论文必须如实写出。
- 网络更稳健的唯一场景是去纹理——这与不依赖表面纹理的 LCb/blank 和 looming 线索相符，而 bypass 更依赖光流幅值。这是
  最值得延伸的方向；Gazebo 测试从 20 个世界扩到 50 个后结论仍然成立。
