# MicoAir MTF-01 下视光流/测距底座

装在机架底板下面，用和 3901-L0X 底座同一组孔（左右 36 × 前后 40 mm，M2，对角方向长条孔 ±2 mm）。v1（2026-11-18），还没有试装。

| 文件 | 说明 |

## 1. 结构

- 一块 2.0 mm 平板贴底板，上面有 4 根 4.0 mm 高的支撑柱。MTF-01 的接口面朝机架、镜头朝地面，4 颗 M2 自攻螺丝从下面穿过载板孔拧进支撑柱（底孔 Ø1.7，可拧深 6 mm，用 M2×6）。
- 载板背面离平板 4.0 mm，放得下 SH1.0 接口座（约 2.9 mm）和插头。
- 三面护墙（机尾侧和左右两侧，厚 2.0 mm），比镜筒端面长出 1.5 mm，落地或磕碰先碰到护墙。机头一侧不做墙：测距发射芯片和接口在这一边，视场不被遮挡，线从这边出。
- 机尾侧护墙上另有一个 16 mm 宽的备用走线缺口，接口如果实际在机尾一边就从这里出线。
- 平板机头一侧有一个三角凸耳，指向机头。
- 外形 45.7 × 50 × 18.9 mm，PLA 约 6.1 g。

## 2. 方向

载板长边横向放。两个镜筒在机尾一侧，测距发射小芯片在机头一侧，这是 ArduPilot/PX4 的默认朝向（官方朝向图）。装反了的话改 `FLOW_ORIENT_YAW` 为 18000，不用重打。

| 底板孔位 | 36 × 40 mm | 用户 10-15 复测（和 3901-L0X 底座相同） |

## 4. 装机注意

1. **高度**：护墙底面在底板下方 18.9 mm，镜筒端面在 17.4 mm。起落脚要比这更低。
2. **光流最小工作距离 8 cm**：停在地面时光流没有读数，起飞后才有。测距最小 2 cm。
3. **遮挡**：护墙端面内沿相对镜筒端面边缘的离轴角，左右 76°、机尾侧 49°；光流视场半角 21°，测距半角 3°。
4. **镜筒比估计值长**：如果实测镜筒高出载板超过 11.5 mm，镜筒会比护墙更低，把 `TUBE_H` 改成实测值重新生成。
5. **打印**：不需要支撑。PETG 或 PLA，壁数 ≥ 3，填充 100%。
