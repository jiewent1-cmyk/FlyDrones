# Raspberry Pi AI Camera 机头座（课程默认摄像头，老师要 10 个）

摄像头：课程 BOM（`ConfigFilesAndInstructions/BOM/ECPS295Fall2026 - Amazon.com.pdf`）里的 **Raspberry Pi AI Camera（Sony IMX500）**。尺寸取自官方 product brief（2024-09）第 4 页机械图。官方说明它的 PCB 外形和孔位和 **Camera Module 3** 完全一样，所以 CM3 / CM2 也能装。

底座和我们的 ELP 机头座（`../3D打印_摄像头机头座`）**完全一样**：两孔横向 27 mm，M2 长条孔左右各能滑 1.5 mm，法兰厚 2.4 mm，光轴朝正前、下倾 12°。

## 1. 结构（插入式，和 ELP 座同一种固定方法）

- 法兰平贴顶板，2 颗 M2 从上往下拧。
- 法兰上立一个夹板框（下倾 12°），**摄像头板从上往下插进槽里**：板正面朝前，传感器模组和镜头顺着前面板的 U 口滑进方窗（14 mm 宽）。
- 槽宽 1.5 mm（板厚 1.0），两侧各留 0.3 mm。背面只有左右两条 2.4 mm 的压边，中间整个敞开，给背面的排线插座（宽 19.6 mm）和元件让位。
- **槽底中间开口**（宽 20.8 mm）：排线插座在板子下沿，排线从这里向下出来，再往后弯，贴着顶板走到 Pi。板子只靠左右两个 2.4 mm 的角落站在槽底上。画面是正的，不用设置旋转。
- 可选：从背面拧 4 颗 M2×3 自攻螺丝（前面板盲孔只有 1.4 mm 深，螺丝长了会顶穿），螺丝头穿过压边上的让位孔直接压在焊盘上，拧进前面板。板子主要靠槽夹住，不拧也行。
- 板子上沿和框顶齐平。拆的时候从槽底开口往上顶板子下沿就行（先拔排线）。

## 2. 关键尺寸（两孔中点为原点）

| 项目 | 数值 |
|---|---|
| 外形 | 37.2（宽）× 17.8（前后）× 31.2（高）mm；法兰从两孔往后伸 4 mm |
| 镜头前端 | 两孔前方约 16.9 mm，顶板上方约 14.8 mm |
| 板下沿背面 | 顶板上方 7.4 mm（法兰上方 5 mm，给排线弯折） |
| 插座背面最靠后的点 | 两孔前方 3.2 mm（螺丝头和螺丝刀从上面下去不受影响） |
| 重量 | 100% 填充约 3.7 g，10 个约 37 g 料 |

视场（66.3° H × 52.3° V）：镜头在整个座子的最前面，所有视场光线都不碰座子；垂直视场下沿（−38°）在两孔前方约 32 mm 处才落到顶板平面。

## 3. 打印

- 用 3MF，法兰贴床，**不需要支撑**：框只往前倾 12°，方窗上方是 U 口，没有桥接。
- PLA 或 PETG 都行（PETG 更韧，槽反复插拔不容易裂）。4 层壁，填充 40% 以上，层高 0.16–0.2 mm。

## 4. 需要核对

| 参数 | 当前值 | 说明 |
|---|---|---|
| `TILT` | 12° | 沿用我们自己的座子。别的组要别的角度，改这个数重新跑脚本就行 |
| 板正面的传感器模组 | 12.8 宽、离上沿 4.36–20.6 mm | 从机械图读的；方窗每边留了 0.6 mm 余量 |
| 两孔到机头前缘的距离 | 不同机架不一样 | 课程默认机架要是没有这对 27 mm 的孔，底座就要改 |
| 槽宽 `SLOT_FIT` | 板厚 1.0 + 2×0.25 | 板子实际更薄、插进去会晃的话，垫一点胶带，或者把 `SLOT_FIT` 改小 |
| 板正面模组下面 | 前面板顶住板正面下沿 2.7 mm | 机械图上这里没有元件；真有东西顶住，把 `WIN_M` 改大 |
| 先打 1 个试装 | — | 确认板子插得进、夹得住，再打 10 个 |
